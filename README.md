🚀 Automating Cookie Clicker using Python & Selenium 🍪🤖
Just built a fun automation project where I used Python + Selenium to play the Cookie Clicker game automatically!
🔧 What this bot does:
Selects language automatically
Continuously clicks the cookie 🍪
Tracks cookie count in real-time
Every 5 seconds → buys the most expensive available upgrade
Runs smart logic to maximize cookie production
Stops after a defined time and prints final result
💡 Key Concepts Used:
Selenium Web Automation
Dynamic element handling
Exception handling (NoSuchElementException)
Time-based execution using time module
Basic decision-making logic (buy best affordable item)
📈 This project helped me understand how automation scripts can simulate human actions and optimize decisions in real-time.
